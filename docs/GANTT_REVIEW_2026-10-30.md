# Planning: сравнение графиков и сценарии — 30.10.2026

## Распределение функций после проверки

| Раздел | Основная задача | Связанные данные и переходы |
| --- | --- | --- |
| Сводка | Готовность наполнения, риски и управленческие действия | Переход к работе, причине риска и сроку |
| График | Импорт, принятие и редактирование версии; подтверждение соответствий | Сравнение перенесено на Гант; отдельный движок сравнения не создаётся |
| Гант | Календарная шкала, сравнение версий, зависимости и выравнивание | Два режима: версии / график и прогноз; КД и назначенная загрузка |
| План / факт | План объёмов, людей и техники против исполнения за период | Общий отбор, месячный / недельный / ресурсный вид |
| Факт | Ежедневный ввод объёмов и людей по работе, журнал событий | Сохраняются общие факты и ресурсные записи, отдельной копии журнала нет |
| Прогноз | Проверка численности и обоснование потребности | Сценарные параметры, сеть и КД; ползунки рядом с точным вводом |
| Ресурсы | Общий журнал людей и техники, распределение и лимиты | Факт из карточки работы попадает сюда же; работа без распределения не выдумывается |
| Объёмы | Физическая ведомость, добавления и исключения | История объёмов отделена от версии графика и журнала факта |
| Ключевые даты | Обязательства и подтверждение выполнения | Прогноз связанных работ не переписывает договорную дату |
| Шахматка | Представление работ по месту и виду | Те же работы в другой раскладке; не отдельный план |
| Мой экран | Конструктор таблицы / отчёта | Повторное представление общих показателей, без отдельного ввода факта |
| Отчёты | Готовые формы и зафиксированные снимки | Исторический выпущенный отчёт отделён от текущего пересчёта |
| Организации | Карточки участников | Общие идентификаторы для импорта, ресурсов и графиков |
| Номерные элементы | Физические сваи / анкеры и история этапов | Факт объёма не подменяется произвольным числом отмеченных элементов |
| Схемы | Документы и отметки выполнения | Ссылки на фронты и элементы; редактор не переносится в Гант |
| Демонтаж | Специальное представление демонтажных фронтов | Профильный раздел сохранён |
| Импорт | Факт / ресурсы и сопоставление справочников | График принимается через профильный импорт графика |
| История | Журнал действий и изменений | Сравнение версий графика не дублируется здесь |
| Настройки | Справочники, календари, доступ и проверка хранения | Лимиты ресурсов доступны в ресурсах; настройки календаря остаются здесь |

## Изменения

- Единственный блок выбора двух версий / дат, KPI и таблицы изменений находится на Ганте. Подтверждение соответствий остаётся в графиках.
- Две полосы используют тот же результат сопоставления, что таблица, включая добавленные, отсутствующие, неоднозначные и укрупнённые строки. Укрупнённая полоса показывает диапазон группы.
- Сравниваются начала, окончания и календарная длительность; контрактное исключение не выводится из отсутствия строки.
- Влияние на связанные КД сравнивается по полному графику, включая работы вне отображаемого отбора. Отсутствующая связь означает неизвестное влияние.
- Вариант Ганта сохраняется при смене версии, старый расчёт сети и выравнивания сбрасывается.
- Группировка сортирует строки по месту или подрядчику; ширина названий регулируется. На телефоне закреплённая колонка ограничена до 170 px.
- Ползунки: состав и выработка (режим производительности), экспертная длительность (ручной режим), окно наблюдения (фактический темп). Выход по датам отключает ползунок постоянного состава. Диапазон ползунка не ограничивает точный ручной ввод.
- Основной прогноз обновляет одну работу сразу; всю сеть и КД нужно пересчитать явно. Изменения сценария не записывают факт или договорные сроки.
- Старые три варианта темпа сохранены в дополнительном раскрывающемся блоке. Представления по фронтам сохранены отдельно: это иной источник, а не удалённая функция.
- Исправлено ошибочное исключение отрицательных этажей из ежедневного ввода и массового редактирования.

## Проверка и границы

Проверены код маршрутизации и взаимодействия вкладок, расчёты и DOM на синтетических данных. Рабочие файлы пользователя не загружались, серверные данные и схема БД не менялись. Полноценная визуальная проверка в живом браузере и на телефоне в этом сеансе не выполнялась. Автоматические тесты не заменяют проверку пользователем его заполненного проекта.
