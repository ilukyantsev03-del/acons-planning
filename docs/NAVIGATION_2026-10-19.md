# Размещение модулей — 19.10.2026

## Основные экраны

| Раздел | Содержимое |
|---|---|
| График | Импорт, создание, таблица, версии и сравнение, подтверждение соответствий, редактор работы и связей, назначения ресурсов, связь работы с КД |
| Гант | Сценарии, расчёт прогноза и критического пути, предпросмотр выравнивания, сохранение новой рабочей версии, временная шкала и ресурсные диаграммы, переносы и влияние на КД |
| План / факт | Периодная аналитика объёмов и готовности, ведомость и история изменения объёмов, ручная раскладка плана, факт выбранного связанного фронта |
| Шахматка | Матрица выбранной версии, разрезы, показатели и сохранённые представления |
| Ресурсы | Доступность групп, плановая дневная потребность графика; существующий журнал и аналитика фактической численности сохранены |
| Ключевые даты | Прогноз связанных КД по выбранной версии и существующий реестр договорных обязательств |
| Сводка | Управленческие отклонения, мероприятия, ответственные, сроки и влияние на КД; существующие показатели проекта сохранены |
| Отчёты | Готовые формы и замороженные отчёты по графикам; создание и просмотр ранее выпущенных снимков по фронтам |
| Настройки | Общий календарь проекта, локальная сверка сохранности и изолированная проверка серверной записи |

Верхняя кнопка «Зафиксировать отчёт» открывает раздел «Отчёты». Существующее окно фиксации среза по фронтам доступно там отдельной кнопкой. Его данные не подменяются показателями графика.

## Общий контекст

Выбранная версия, выбранная работа, период, фильтр организаций и предварительный расчёт общие для профильных экранов. Смена версии и периода отражается на остальных экранах. Обычный переход между вкладками не сбрасывает расчёт. Переход по работе с Ганта, из шахматки или управленческого обзора открывает её редактор в «Графике».

Новые блоки существуют в одном экземпляре; обработчики действуют в их целевых вкладках. Перенос интерфейса не создаёт копии проектных данных. При изменении исходных данных в другом разделе или замене проекта устаревшие представления и расчёты сбрасываются. Изменение ползунков немедленно снимает возможность сохранения прежнего расчёта и скрывает его производные таблицы до обновления.

## Представления по фронтам

Прежние Гант, шахматка и план/факт по фронтам сохранены в раскрываемом блоке «… по фронтам — отдельное представление». При наличии принятой версии основным становится новое представление графика. Если принятой версии нет, прежнее представление раскрыто, а новый блок объясняет, как создать график.

Это разные источники представления, а не две копии одного графика. Перенос не преобразует фронты в задачи и не придумывает отсутствующие связи. Выбор одного слоя в прежнем Ганте остаётся прежним; одновременный показ всех пяти слоёв в этот пакет не входит.

## Проверки

Искусственные данные: профильное размещение и уникальность ID; общая версия и период; настоящая функция переключения вкладок; сохранность предварительного расчёта при переходах; смена проекта; действия из управленческого обзора; сохранение доступности ресурсов, факта и готового отчёта кнопками целевых экранов; очистка устаревшего прогноза после ползунка; доступность ранее зафиксированных снимков без графика. Рабочие файлы и серверные записи в проверках не используются.

DOM-тесты проверяют структуру и действия. Полная визуальная проверка в авторизованном браузере остаётся пользовательской приёмкой.
