Журнал сервера подтвердил отмену INSERT construction_project_snapshots по statement_timeout. На момент диагностики лимит authenticated — 8 секунд; исходный снимок — 14 374 080 байт, 19 844 записи ресурсов. Небольшой новый проект «Рахиль» уже создан; ошибка переключения не означает, что его нужно создавать повторно.

Сохранение переведено в атомарную функцию save_construction_snapshot с отдельным лимитом 30 секунд. Она выполняется с правами вызывающего пользователя, сохраняет RLS, проверку идентификатора проекта, монотонную ревизию и авторство. Анонимный вызов запрещён. Глобальные лимиты и политики доступа не менялись.

Повторные одновременные сохранения одинакового документа объединяются. Повтор подтверждённого документа сверяет только серверную ревизию; конфликт не скрывается и не перезаписывается. После сбоя документ не считается сохранённым, повтор остаётся возможным. Сообщение о тайм-ауте переведено на русский.

Скорость указана для SQL-проверки, а не для полного HTTP-запроса из пользовательского браузера. Финальная проверка пользовательского сохранения выполняется после публикации. Перед обновлением страницы с неподтверждёнными изменениями нужно скачать резервную копию: начальная серверная загрузка способна заменить локальное состояние более старым подтверждённым снимком.
