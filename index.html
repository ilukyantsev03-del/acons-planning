Публичный доступ сейчас

Текущая GitHub Pages версия — публичная ссылка без авторизации. Не размещай здесь конфиденциальные данные.

Для реальной эксплуатации нужен вход по учетной записи и база данных. Я подготовил структуру под Supabase: после подключения можно ограничить доступ по ролям и по проектам.

Как выдавать доступ после подключения базы

Внутренние сотрудники
Вход по email → роль Планировщик / Ответственный / Администратор.
Заказчик
Отдельная учетная запись → только чтение → только разрешенные объекты и отчеты.
Подрядчик
Доступ только к своим работам → ввод факта и комментариев без прав менять договорные даты.
