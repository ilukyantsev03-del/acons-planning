# LIV Planning — правила импорта

## Общий процесс

Любой рабочий импорт проходит этапы:

1. загрузка файла;
2. определение типа;
3. распознавание колонок;
4. нормализация;
5. умное сопоставление;
6. предпросмотр изменений;
7. подтверждение пользователем;
8. запись в рабочие сущности;
9. журнал импорта;
10. возможность отката.

До подтверждения импорт не должен менять рабочую базу.

## Умное сопоставление

Порядок поиска:
1. сохраненное source mapping;
2. точное имя;
3. alias;
4. нормализованное имя;
5. уверенное похожее совпадение;
6. новое значение.

Подтвержденное сопоставление запоминается.

При переименовании справочника старое имя сохраняется как alias.

## Ключевые даты

Минимально поддерживаются:
- Подрядчик;
- № договора;
- Наименование КД;
- Дата окончания.

Дополнительно:
- Здание;
- Блок/захватка;
- Этаж/номер захватки;
- Дата начала;
- Длительность;
- Факт;
- Статус;
- Отклонение.

Если номер договора отсутствует в справочнике, создается договор для соответствующего подрядчика.

Из формулировки КД система может извлечь целевой объем, например:
- 190 свай → 190 шт.;
- 500 м³ → 500 м³.

## Рабочие графики

График сначала импортируется в тестовый контур.

Поддерживаются:
- ID задачи;
- структурный номер / WBS;
- текущие даты;
- базовые даты;
- договорные даты;
- фактические даты;
- длительность;
- процент;
- предшественники;
- последователи;
- лаги;
- объем;
- подрядчик.

Перед принятием показывается сравнение с текущим графиком:
- новые;
- измененные;
- без изменений;
- отсутствующие в новой версии;
- количество зависимостей.

## Факты

Дневной факт и накопительный итог — разные типы данных.

- дневной объем → fact_type=quantity;
- накопительный показатель → fact_type=cumulative_snapshot.

Нельзя суммировать cumulative_snapshot как обычный дневной факт.

## Номерные элементы

Ключ уникальности:
Проект + Тип + Здание + Группа/ярус/марка + Захватка + Зона + Номер.

Примеры:
- РЧВ / БНС-2 / №93;
- Дроп-оф / БСС-1 / №93 — допустимо одновременно;
- Г1 / №7 и Г2 / №7 — допустимо одновременно;
- повтор Г1 / №7 — дубль.

## Источник записи

Импортированная запись по возможности хранит:
- source_file;
- source_sheet;
- source_row;
- source_batch_id;
- source_fingerprint.

Это необходимо для повторного импорта, отката и аудита.
