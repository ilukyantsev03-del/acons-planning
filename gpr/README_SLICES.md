# Единые срезы графиков

Все графики, открываемые через index.html (фасады) или mockup.html (остальные профили), используют cuts.js и cuts.css. Новым графикам не нужно создавать собственную таблицу сравнения.

- Общая граница истории — 17.11.2026. Это нижняя граница доступных дат, а не выдуманное состояние: если график ещё не существовал, выводится «Нет данных».
- gpr_cut_state восстанавливает состояние на конец выбранного дня по Москве обратным проходом gpr_history. Таблица истории уже автоматически пополняется триггером при изменениях gpr_items. RPC проверяет право чтения конкретного графика и не возвращает личности из аудита.
- Обе даты сравниваются с одной выбранной базой. Динамика = отклонение окончания на вторую дату минус отклонение на первую. Плюс — ухудшение, минус — улучшение.
- Уточнения хранятся отдельными meta-записями cut-adjustment-UUID. Они не изменяют задачи или базу. Причина обязательна; исходные записи и отмена уточнения остаются в истории. Последняя серверная запись для позиции и даты имеет приоритет.
- Печать использует общий report.js, режим dynamics: А3/А4, число страниц, заголовок по фильтрам, отключаемые даты и причины. Наличие уточнений отмечается независимо от показа подробностей.
- Права редактирования остаются прежними: интерфейс уточнений доступен владельцу, запись защищена существующей политикой gpr_items.
